  BEGRUENDUNG ROOT: Dienste die root brauchen sind solche die
  Kernel-Netzwerk-Operationen ausfuehren (nftables, WireGuard Peer-
  Management, IPsec/L2TP, PPP-Interfaces). Das ist keine Bequemlichkeit
  sondern technische Notwendigkeit.

  VPN-TOOLING:
    vpn-policy-apply            root (nft + tc + ppp-kill)
    vpn-accounting-collector    root (Interface-Counter lesen)
    vpn-session-kill            root (ppp-kill, nft)
    vpn-stale-session-janitor   root (DB + ggf. ppp-kill)

================================================================================
2) PRIVILEGE SEPARATION (aus B167 + B285)
================================================================================

  REGEL: Panel (www-data) darf NIEMALS direkt:
    - nft-Regeln aendern
    - tc-Klassen aendern
    - PPP-Sessions killen
    - VPN-Interfaces manipulieren

  STATTDESSEN: Panel ruft vpn-policy-apply und vpn-session-kill
  via sudo (eingeschraenkt auf diese beiden Tools mit validierten
  Argumenten). Quelle: B167 §5, B285.

  SUDOERS-REGEL (Konzept):
    www-data ALL=(root) NOPASSWD: /usr/local/bin/vpn-policy-apply *
    www-data ALL=(root) NOPASSWD: /usr/local/bin/vpn-session-kill *
