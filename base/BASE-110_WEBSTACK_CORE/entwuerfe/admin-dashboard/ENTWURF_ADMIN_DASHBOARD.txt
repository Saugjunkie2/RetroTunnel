================================================================================
1) CONNECTION-UEBERSICHT (filterbar, durchsuchbar)
================================================================================

  - Alle Connections als Tabelle
  - Filter: Customer, Tunnel-Typ, Status, Rolle
  - Suche: connection_ref, subaccount_login, Customer-Email
  - Sofort sichtbar: Welche Connection gehoert zu welchem Account
  - Live-Status: Wer ist gerade verbunden (aktive Session ja/nein)
  - Sortierung nach beliebiger Spalte

================================================================================
2) CREDENTIAL-VOLLZUGRIFF (Admin)
================================================================================

  - Admin sieht ALLE Credential-Daten jeder Connection:
    L2TP: subaccount_login + Klartext-Passwort
    WG: Vollstaendige Config + QR-Code + Keys
  - Admin kann Credentials rotieren (Passwort-Reset, Key-Rotation)
  - Admin kann Connections bearbeiten, disablen, restoren
  - INV-75/INV-80: Admin hat Vollzugriff, Panel ist Sicherheitsgrenze

================================================================================
3) TRAFFIC-VERBRAUCH PRO CONNECTION
================================================================================

  - Traffic-Volumina (RX/TX) pro Connection und Zeitraum
  - Wie oft Limit ausgeschoepft (wenn QoS/Quota aktiv)
  - Gesamtverbrauch pro Customer (alle Connections summiert)
  - Historische Entwicklung (Grafik/Trend waere ideal)

================================================================================
4) HEAVY-USER-ERKENNUNG
================================================================================

  - Ranking der Connections nach Traffic-Verbrauch
  - Warnung bei ueberproportionalem Ressourcenverbrauch
  - Identifikation von Usern die "alle Resourcen leersaugen"
  - Filterbar nach Zeitraum (letzter Tag / Woche / Monat)

================================================================================
5) DNS-QUERY-EINSICHT (AdGuardHome-Integration)
================================================================================

  - Pro Connection-IP die besuchten Domains anzeigen
  - Wichtigste AdGuardHome-Funktionen im Webpanel integriert:
    Query-Log, Top-Domains, Blockierte Requests
  - Nicht ALLE AdGuardHome-Features, aber die wichtigsten
    fuer Admin-Pruefung und Support
  - Technisch: AdGuardHome hat eine API, Connection-IP als Schluessel
  - Wuenschenswert: Direkt im Panel, nicht im AdGuardHome-Webinterface

================================================================================
6) LOG-VIEWER (zentraler Zugang ueber Panel)
================================================================================

  Marco: "Wo die Logs auf dem Server liegen ist mir egal —
  Hauptsache ich kann sie im Webpanel einsehen und durchsuchen."

  - Zentrale Log-Ansicht im Panel:
    Auth-Logs (radpostauth: wer hat wann versucht sich zu verbinden)
    Lifecycle-Logs (log_connection_lifecycle: Statuswechsel)
    Session-Logs (vpn_sessions: offene/geschlossene Sessions)
    System-Logs (relevante systemd-Unit-Logs)
  - Suchfunktion in allen Logs (Freitext, Filter nach Zeitraum)
  - Filter nach Connection, Customer, Event-Typ
  - KEIN SSH noetig um Logs zu sehen

================================================================================
7) AUTH-HISTORIE
================================================================================

  - Letzte Login-Versuche pro Connection (ACCEPT/REJECT)
  - Reason-Code bei Ablehnung (warum abgewiesen?)
  - Zeitstempel, Quell-IP
  - Quelle: radpostauth (L2TP), AWG-Controller-Logs (WG)

================================================================================
8) RESTRICT/DISABLE-HISTORIE
================================================================================

  - Wann wurde welche Connection eingeschraenkt/deaktiviert
  - Welcher Reason-Code, welcher Akteur (ADMIN/SYSTEM/JOB)
  - Restore-Historie
  - Quelle: log_connection_lifecycle

================================================================================
9) BATCH-OPERATIONEN
================================================================================

  - Mehrere Connections gleichzeitig disablen (z.B. Abuse eines Kunden)
  - Bulk-Passwort-Reset
  - Massenaktionen mit Bestaetigung (Re-Auth fuer Klasse-C)

================================================================================
10) QUELL-IP-LEAK-WARNUNG
================================================================================

  - Panel vergleicht anfragende IPs pro Connection
  - Bei Verdacht auf Credential-Leak: Hinweis an User (Empfehlung)
  - Kein Zwang, keine automatische Sperre
  - Marco-Entscheidung: Server-Sicherheit > User-Credential-Schutz

================================================================================
11) SYSTEM-STATUS / HEALTH
================================================================================

  - RADIUS-Health: DB-Verbindung, Queue-Tiefe
  - WireGuard-Status: Dienst laeuft, DB-Health-Check-Status
  - Aktive Sessions: Anzahl L2TP + WG
  - Disk/CPU/RAM Uebersicht (Basisdaten)
  - Timer-Status: Alle systemd-Timer sichtbar

================================================================================
OFFENE FRAGEN (bei MOD-006 Ausarbeitung zu klaeren)
================================================================================

  - AdGuardHome-API-Integration: Scope? Nur Query-Log oder mehr?
  - Traffic-Daten: Echtzeit oder Batch-aktualisiert?
  - Log-Retention im Panel: Wie weit zurueck?
  - Dashboard-Layout: Einzel-Connection-Detail vs. Ueberblick-Grid?
