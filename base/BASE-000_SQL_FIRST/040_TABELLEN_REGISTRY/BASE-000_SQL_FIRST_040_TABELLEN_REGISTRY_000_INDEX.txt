================================================================================
BASE-000 — TABELLEN-REGISTRY — INDEX
================================================================================
DATEI: BASE-000_SQL_FIRST_040_TABELLEN_REGISTRY_000_INDEX.txt

Diese Registry ist die EINE Quelle fuer Tabellennamen. Jede andere Datei
(DOMAIN_MODEL, State Machines, Base-Module) referenziert diese Namen.
Wenn eine andere Datei einen anderen Namen verwendet, ist sie falsch.

================================================================================
EINTRAGS-SCHEMA (jeder Registry-Eintrag folgt diesem Raster)
================================================================================

  Jeder Eintrag MUSS mindestens enthalten:

  tabellenname                                          [STATUS, OWNER]
    Zweck: Was die Tabelle speichert (1-2 Saetze).

  Zusaetzlich wenn zutreffend:
    FK: fremdschluessel -> zieltabelle.id (Kardinalitaet)
    Altname: "alter_name" (DOMAIN_MODEL §x) — wenn umbenannt
    KORREKTUR: Erklaerung der Umbenennung — wenn Altname existiert

  STATUS: BESTEHEND | NEU | GEPLANT
  OWNER: Welches Base-Modul das Schema definiert (z.B. BASE-010)

NAMING-KONVENTION:
  Alle Dateien tragen den vollstaendigen Pfad als Prefix im Dateinamen
  (bewusste Redundanz / selbstbeschreibende Dateinamen). Jede Datei
  funktioniert auch ohne Ordnerkontext — der Name allein sagt woher
  sie kommt und wozu sie gehoert.
