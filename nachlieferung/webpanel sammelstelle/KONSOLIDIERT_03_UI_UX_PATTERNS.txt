1. 3-STUFEN TOOLTIP-SYSTEM
============================

| Ebene          | Wann sichtbar          | Beispiel                           |
|----------------|------------------------|------------------------------------|
| Tooltip        | beim Hover             | "Hier kannst du Bilder hochladen." |
| Info-Icon      | klickbarer Hinweis     | "Nur PNG & JPG erlaubt, max 5 MB." |
| System-Hinweis | direkt sichtbar        | "Du hast noch keine Galerie."      |

- Einheitlicher Einsatz im Adminpanel UND Frontend
- Immer in freundlichem Elara-Ton
- Auch in Character-Stil moeglich (Hulk-Tooltips etc.)


2. FEELGOOD-ELEMENTE
======================

| Element                  | Beschreibung                                    |
|--------------------------|-------------------------------------------------|

3. ZITAT-BEGRUESSUNGSSYSTEM
=============================

- Erscheint beim ersten Aufruf einer neuen Session
- Nur wenn min. 2 Stunden seit letztem Besuch vergangen
- Sanft schwebend unten mittig, 2,5 Sekunden Anzeigedauer
  (0,5s Fade-in, 1,5s sichtbar, 0,5s Fade-out)
- Seite bleibt sofort benutzbar — kein blockierendes Overlay
- Klick oeffnet optionale Infobox oder fuehrt zu "Ueber uns"
- User kann Zitate im Profil deaktivieren
- Admin verwaltet Zitat-Pool im Adminpanel (CRUD)
- User kann eigenes Lieblingszitat hinterlegen
- Technisch: JavaScript, Cookie + Zeitstempel, DB-gestuetzt


4. ADMIN-COACHING-MODUS (3 STUFEN)
====================================

"Die stille Assistenz & das sanfte Rettungsnetz"

STUFE 1: STILLE VORBEREITUNG (Textbaustein-Bibliothek)
  - Persoenliche Textbaustein-Bibliothek im Backend
  - Wiederkehrende Textbloecke fuer Beschreibungen
  - Beschreibung aus Bausteinen komponieren
  - Routine wird zum kreativen Akt des Zusammenfuegens

STUFE 2: BEWUSSTER ABGLEICH (Wahrheits-Abgleich)
  - System bleibt waehrend des Erstellungsprozesses STILL
  - Keine stoerenden Echtzeit-Hinweise
  - Erst auf Knopfdruck: "Elara, schau bitte einmal mit mir drueber"
  - Dann: interner Abgleich (strukturierte Daten vs. Beschreibungstext)
  - Optional: externer Abgleich mit externen Quellen
  - Interaktion: Felder mit Unstimmigkeit bekommen sanfte leuchtende
    Umrandung + Hinweistext direkt unter dem Feld
  - Korrektur → Umrandung und Hinweis verschwinden sanft

STUFE 3: AUTOMATISCHE VOLLENDUNG (Bildverarbeitung)
  - Bilder hochladen → System uebernimmt automatisch:
    Groessenanpassung, Optimierung, korrekte Speicherung
  - Stille Assistenz ohne manuellen Eingriff


5. VALIDIERUNG & FORMULARLOGIK
================================

- Pflichtfelder: Elara-Fehlermeldung ("Da fehlt noch etwas Magisches...")
- Optionale Felder leer: im Frontend nicht angezeigt
- Technisch noetige Felder: automatisch gesetzt (IDs, Timestamps)
- Serverseitige Validierung: Formate, Groessenlimits, positive Zahlen
- Dropdownwerte im Adminbereich aenderbar
- Neue Kategorien jederzeit einfuegbar
- Erweiterung durch Plugins moeglich


6. PORTAL-BLOCK-VERWALTUNG
============================

6.1 STANDARDAUFBAU (fuer neue Benutzer)
  1. Willkommenstext (optional, ausblendbar)
  2. Ankuendigungen (Pflicht, wenn aktiv)
  3. Neueste Beitraege (immer sichtbar)
  4. Umfragen (optional)
  5. Retrowork Updates (immer sichtbar)
  6. Changelog / Entwicklung (optional)

6.2 ADMIN-STEUERUNG
  - Sichtbarkeit jedes Blocks (an/aus)
  - Verschiebbarkeit (fixiert/flexibel)
  - Standardspalte (Links/Mitte/Rechts)
  - Reset auf Standard fuer einzelne User oder global

6.3 BENUTZER-STEUERUNG (wenn erlaubt)
  - Bloecke verschieben innerhalb erlaubter Spalten
  - Bloecke ein-/ausblenden
  - Persoenliche Portalansicht speichern
  - Jederzeit Reset auf Admin-Standard
  - Gaeste sehen nur Admin-definierte Ansicht

6.4 ADMIN-GLOBALE AKTIONEN
  - Theme/Modus fuer alle User gleichzeitig setzen
  - Betroffene User werden informiert: "Layout wurde zurueckgesetzt."
  - Individuelle Benutzerpflege: Einstellungen einsehen/reparieren/
    auf Standard zuruecksetzen
  - Backup der User-Config vor Reset moeglich
  - Testmodus: Seite aus Sicht eines Users aufrufen


7. DYNAMISCHE SYMBOL- UND FARBBASIERUNG
==========================================

- Symbole, Statusanzeigen, Markierungen sind themeabhaengig
- Trophaeeen, Ankuendigungen, FAQs: Icons und Farben variieren
- Feelgood-Animationen stimmen sich auf aktives Theme ab
- Beim Themewechsel passt sich alles automatisch an
- Jedes Theme definiert eigene Farben, Icons, Animationstypen


8. BENUTZERPROFIL-UX-PATTERNS (adaptierbar)
=============================================

- Mini-Signatur (Text + optional kleines Bild)
- Kurzbeschreibung
- Erster Profilgruss von Elara
- Online-/Offline-Status (dezent, themeabhaengig, abschaltbar)
- Avatar (mit Moderations-Schutz)
- Persoenliche Startseite (nach Login: Hauptseite/Forum/Profil)
- Favoriten (Herz-Icon, eigener Block/Tab)
- Lesezeichen (privat, Update-Benachrichtigung)
- Privacy-Tooltips und jaehrlicher Check
- Entwuerfe automatisch lokal gespeichert
- Drag & Drop Upload fuer Anhaenge
- Erstbeitragspruefung (freundlich)
- Erfolgs-Trophaeeen (themeabhaengig, sanft)
- Admin: Profile einsehen, zuruecksetzen, Testmodus, Notizen, Historie
