1. BENUTZERVERWALTUNG & ROLLEN
================================

Status: Modular als Plugin, aktivierbar/deaktivierbar.
Aktuell nur Admin, aber vorbereitet fuer vollstaendiges User-Management.

Rollen-Hierarchie:
  - Admin (System-Admin, volle Rechte)
  - Moderator (eingeschraenkte Verwaltung, kein Override)
  - User / "Reisender" (Standardnutzer)
  - Gast (nur oeffentliche Inhalte, keine Interaktion)

Features:
  - Detaillierte Rechte pro Modul
  - Kombination aus Rollen + individuellen Freigaben
  - Aenderungen werden protokolliert (Timeline)
  - Zugriff auf geschuetzte Bereiche: Login + Session-Token
  - Userprofile, Aktivitaetslog, Notizen
  - Soft- & Hardbann (mit freundlicher Erklaerung)
  - Accountpflege durch Admin
  - DSGVO-konformer Export aller eigenen Daten (ZIP/PDF)

Philosophie: "Rollen sind keine Grenzen, sondern Formen von Naehe.
Zugriff entsteht aus Vertrauen, nicht aus Hierarchie."


2. FAQ-SYSTEM
==============

Mehrstufige, durchsuchbare FAQ nach Feelgood-Prinzip.

Struktur:
  - Kategorien: Technik, Software, Philosophie, Organisation
  - Beitraege: Frage + Antwort + optionaler Link + Tags
  - Sortierung: Haeufigkeit, letztes Update, manuelle Prioritaet
  - Liebevolle Formatierung (sanfte Ueberschriften, kurze Absaetze)

Erstellung:
  - Admin/Moderator erstellt/bearbeitet
  - Minimale Eingabemaske: Frage, Antwort, Links, Tags, Sichtbarkeit
  - Jede Aenderung erzeugt neue Version im Log
  - User sehen nur veroeffentlichte, gepruefte Eintraege
  - User koennen Vorschlaege einreichen

Extras:
  - Top-Fragen, Akkordeon-Darstellung, Sofortsuche
  - Favoriten, downloadbare FAQ-PDF
  - API-Anbindung


3. NEWS & CHANGELOG-SYSTEM
============================

News-Bereich (Frontend):
  - Oeffentliche Mitteilungen und Updates
  - Kurz, verstaendlich, optisch ruhig
  - Karten mit Datum, Version, Kurztext

Changelog (Admin/Intern):
  - Vollstaendige Uebersicht aller Aenderungen
  - Pro Version: Versionsnummer, Datum, Kategorien
    (Neu / Verbessert / Entfernt / Gedanke), Freitextbeschreibung
  - Admin entscheidet welche Eintraege im Frontend sichtbar
  - Aeltere Eintraege bleiben erhalten, archivierbar

Parallel: /data/changelog.txt als Dateisicherung


4. DOWNLOAD-BEREICH
=====================

Zentrale Ablage fuer Dateien, Tools, Anleitungen.

Features:
  - Kategorien & Unterkategorien
  - User-/Gruppenrechte, Einzelberechtigungen
  - Beschreibung, Versionierung, Changelog/History
  - Kommentar-/Bewertungsfunktion (abschaltbar)
  - Zeitlimit/Auto-Loeschfunktion
  - Downloadstatistiken
  - Optional: API

Philosophie (Marcos Originalgedanke):
  "Wenn jemand das selber machen will, bekommt er bei mir keine
   Anleitung, aber er kann sich die Daten runterladen und es
   versuchen. Und wenn er es nicht hinbekommt, kann er sich
   melden und ich richte ihm das gegen Bezahlung ein."


5. TIMELINE / ERINNERUNGSSYSTEM
=================================

5.1 TIMELINE (Projektchronik)
  - Chronologische Darstellung von Events, Meilensteinen, Releases
  - Automatische + manuelle Eintraege
  - Zwei Modi: Intern (Admin) und Oeffentlich (optional)
  - Filter nach Zeitraum, Typ, Benutzer
  - Suche nach Schlagworten
  - Export als Text, CSV, PDF
  - Gruppierung: Heute, Gestern, Letzte Woche, Aelter

  Automatische Eintraege bei:
    Export, Plugin-Installation, Kommentarfunktion aktiviert

5.2 ERINNERUNGSSYSTEM (v2.0)
  - Erinnerung aktiv: Ja/Nein mit optionalem Datum + Beschreibung
  - Erinnerungstyp (Technik, Text, Preis, Nachfassen, Bilder fehlen)
  - Dringlichkeitsstufe (Niedrig/Mittel/Hoch, farblich hervorgehoben)
  - Dashboard-Widget: "Erinnerungen: 3 offen..."
  - Hinweis bei Login: "Du hast X Erinnerungen aktiv"
  - Kalenderansicht, Filtermoeglickeit
  - Export als Notiz-Log (CSV/PDF)


6. GAESTEBUCH & KONTAKT
=========================

6.1 GAESTEBUCH
  - Kein Feedbacksystem, kein Kommentarbereich
  - Ort fuer ehrliche Worte, stille Spuren
  - Formular: Name (Pflicht), Nachricht (Pflicht), E-Mail (optional, intern)
  - Moderationsstatus: Warteschlange → Admin-Freigabe
  - Darstellung: ruhige Listenform ohne Avatare/Zaehlung/Bewertung
  - Optionale Admin-Antwort unter Eintrag

6.2 KONTAKTFORMULAR
  - Felder: Name, E-Mail, Betreff, Nachricht
  - Nachrichten im Adminbereich gelistet (beantwortbar, archivierbar)
  - Spam-Schutz
  - Automatische E-Mail-Benachrichtigung an Admin


7. BACKUP & WIEDERHERSTELLUNG
================================

  - Backup-Knopf im Adminbereich: komplette Seite + DB in ZIP
  - ZIP enthaelt alles zur Wiederherstellung (inkl. Readme)
  - Wiederherstellung durch Upload + einfache setup.php mit Pruefung
  - Optional: Cloud-Backup-Anbindung (WebDAV, FTP)
  - Taeglich automatisch oder manuell ausloesbar
  - Datumsbasierte Benennung
  - Vorschau-Modus (Dry-Run) vor Ruecksicherung
  - Zeitstempel-Validierung (verhindert Downgrades)
  - Integritaetspruefung (Hash-Vergleich)


8. HEALTH-MONITOR & DIAGNOSE
===============================

8.1 SYSTEMUEBERSICHT (Dashboard)
  - DB-Verbindung, Schreibrechte, Server-Infos
  - Letzte Sicherung, letzter Export, letzter Login

8.2 DETAILLIERTE DIAGNOSE
  - Kodierung (UTF-8-Check), Modul-Status
  - API-Erreichbarkeit, Datei-Integritaet
  - Automatische Schnellpruefung: Gruen/Gelb/Rot
  - Manuelle Tiefenpruefung auf Knopfdruck
  - Berichts-Export als PDF/TXT

8.3 RUECKMELDUNGEN
  - "Alles in Balance."
  - "Ein Bereich braucht deine Aufmerksamkeit."
  - Tooltip-Erklaerungen in normaler Sprache


9. WARTUNGSMODUS
==================

  - Aktivierung durch Admin mit optionalem Timer
  - Besucher sehen: "Retrowork macht gerade Ordnung."
  - Admin-Zugriff bleibt moeglich
  - Automatische Reaktivierung nach Ablauf oder manuell
  - Health-Monitor erkennt aktive Wartung
  - Timeline vermerkt Beginn/Ende
  - Diagnose wird nach Abschluss automatisch ausgefuehrt


10. API & EXPORT-SYSTEM
=========================

  Endpunkte (modulbasiert):
    admin_status, theme_get/set, plugin_list, visitor_stats,
    backup_trigger, system_check, sync_trigger

  Authentifizierung:
    Admin-Token oder API-Schluessel, Rechtevergabe nach Modul

  Datenausgabe:
    JSON (Standard), optional CSV, XML

  Import:
    Pruefung auf Duplikate/Konflikte/Versionsnummern
    Vorschau-Modus ("Test-Import")
    Nichts wird einfach ueberschrieben — alles protokolliert

  Datenschutz:
    Keine personenbezogenen Daten in oeffentlichen Endpunkten
    DSGVO-konformer Export
    Protokollierung jeder Abfrage (Zeit, IP, Token)
    API-Schluessel temporaer deaktivierbar/erneuerbar

  Plugins koennen eigene Endpunkte definieren.


11. SEO-GRUNDLAGEN
=====================

  - Sprechende URLs / Slugs (automatisch generiert, manuell anpassbar)
  - Meta-Titel + Meta-Beschreibung pro Seite mit Live-Editor
  - Alt-Texte fuer alle Bilder (Pflicht)
  - Strukturierte Daten (schema.org, JSON-LD)
  - Responsive Design / Mobile First
  - Accessibility (Kontrast, ARIA, Tastatursteuerung)
  - sitemap.xml + robots.txt (automatisch)
  - OpenGraph + Social Media Tags
  - Korrekte H1-H6 Struktur
  - Lazy Loading, minifizierte Skripte
  - Canonical-Tags (automatisch)
  - 404-Fehlerseiten (freundlich, mit Suchfunktion)
  - RSS-/Atom-Feeds fuer News/Changelog
  - Content-Aging: "Zuletzt aktualisiert am..." + Health-Monitor-Warnung
  - Mehrsprachigkeit mit hreflang-Tags
