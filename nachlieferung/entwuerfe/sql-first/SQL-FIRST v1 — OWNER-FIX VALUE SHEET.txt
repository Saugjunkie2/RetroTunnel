A) Architektur-Entscheide (Owner-FIX)
================================================================================
DEC-SQLF-001: SINGLE_DB = TRUE
- Aussage: Es gibt exakt EINE DB für System + Webpanel (kein Split).
- Impact: DB-Schema-Core (B055), Panel-Views, RADIUS AAA, Accounting, Settings-Katalog.

DEC-SQLF-002: SQL_FIRST_IS_FOUNDATION = TRUE
- Aussage: SQL-first ist Fundament (kein “optional nice-to-have”).
- Policy-Relevantes gehört in settings_catalog; keine Magic Numbers in Code/Configs.

DEC-SQLF-003: PREFIX_NAMESPACE_POLICY = ENABLED
- Aussage: Settings-Keys werden nach Funktionsdomäne präfixiert (Namespace).
- Minimal erlaubte Präfixe (Owner-FIX):
  • web_
  • vpn_
  • peak_
  • radius_
  • settings_
  • log_
  • spool_

DEC-SQLF-004: DRIFT_MODEL = OPTION_C_CORRECTED
- Aussage: Hard-configs/Datei-Referenzen sind Drift-Detektor/Panel-Hinweis (und optional Auto-Repair),
  NICHT “Policy gilt ohne DB”.
- /diag + Panel müssen Drift maschinenlesbar + menschlich erklärbar anzeigen.

DEC-SQLF-005: PANEL_IS_CENTRAL_CONTROL_PLANE = TRUE
- Aussage: Webpanel ist die Zentrale: sehen + steuern + verstehen.
- Referenz (Kanon, akzeptiert): decisions/D003 (Single Webpanel Surface).
