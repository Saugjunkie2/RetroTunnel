CROSS-CHECK RESULTAT
================================================================================
- Diese 8 Keys sind in Kanontexten als SQL-first/policy-relevant genannt, aber im B057-Startset aktuell NICHT als Canonical-Key geführt.
- Konsequenz: SQL-first bleibt an diesen Stellen “SQL-Sand”, weil Consumer entweder implizite Defaults brauchen oder undefiniert bleiben.

COLLATERAL FINDINGS (nicht Key-Liste, aber relevant für Drift-Modell):
- B330/B165 nennen lokale HARD Ceilings (LOG_HARD_MAX_BYTES / SPOOL_HARD_MAX_BYTES / SPOOL_HARD_MAX_AGE_SECONDS) als MUST-Enforcement.
  Das kollidiert potenziell mit eurer korrigierten Option C, wenn C so verstanden wird, dass 'Hard Config' nur Drift-Hinweis ist.
  -> Im SQL-first Entwurf wird das als OPEN geführt (siehe OPEN REGISTER: SQLF-OPEN-DRIFT-01).
